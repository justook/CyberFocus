# CyberFocus 个人中控台

一个集时间管理、任务规划、专注计时于一体的现代化个人效率中心平台。纯前端实现，**零构建、零框架、零后端**，所有数据保存在浏览器本地。（当前版本 v0.10.0）

## ✨ 功能特色

### 🎛️ 核心仪表盘
-   **数字时钟**: 大字号时间显示，支持公历与农历日期切换。
-   **多源搜索**: 集成 Bing、Google、Google Scholar 快速搜索入口。
-   **实时天气**: 
    *   基于**高德地图 API**。
    *   支持城市搜索与切换。
    *   提供基于天气的实时出行建议。
    *   *注意：内置了 CORS 代理自动回退机制，解决跨域请求问题。*
-   **每日 Bing 壁纸**: 可选启用，自动缓存避免重复请求。

### ⚡ 快速访问
- 自定义常用网站快捷方式
- 支持编辑模式，可添加、修改或删除快捷链接
- 玻璃拟态设计风格，美观实用

### 🧭 个人导航页（第二屏，可管理）
- 分组化的网址收藏，带目录索引与滚动高亮
- **管理面板**：导航页右上角滑杆按钮进入，支持分组/链接的增删改、拖拽换组与排序、重命名、恢复默认
- 数据存于本地 `localStorage`（键 `cyberNavConfig`），首次启动以内置 23 条种子数据初始化，之后改动完全属于你自己
- 图标：优先使用内置图标，新增链接自动取 favicon（色块+首字母兜底，离线可用）；内网/本地地址不会向第三方发送域名
- **外部投递通道**：支持 `#add=<base64url(JSON)>` hash 参数与剪贴板导入，配合官方浏览器插件实现收藏（人工点击弹出预填确认框可选分组/图标，带 `group` 参数的投递按指定分组静默落库）；同 URL 自动去重


### 📝 任务管理系统（三个页签 + 归档）
- **待办事项**：日常零散任务记录
- **今日计划**：当天具体执行计划，支持贡献度分配
- **本周目标**：周度宏观目标设定，可一键"加入今日计划"拆解执行
- **归档**：往期已完成的今日任务按日期归档，可随时退回今日重做
- 支持父子任务关联，形成目标树状结构
- 可视化进度追踪：父任务进度 = 保留进度 + 子任务贡献之和，支持显式权重或自动均分
- 智能截止时间提醒（紧急/警告/正常三级标识）
- 往期未完成任务自动"顺延"到今天并带角标提示，不会静默消失
- 每日任务自动重置：可标记任务为每日重复，系统会在每天首次访问时自动重置状态（页面挂着过夜也能跨零点自动重置）
- 任务编辑功能：双击任务可编辑内容、截止时间和其它属性
- 任务计时功能：可对每个任务进行单独计时，采用心跳收账机制，挂机过夜不会虚增时长
- 任务拖拽排序（归档视图除外）

### ⏳ 番茄工作法专注计时器
- 可视化倒计时圆环（真实进度环，按已用时间精确推进）
- 可自定义专注时长
- 完整的开始/暂停/重置控制
- 专注结束音效提醒（音频不可用时自动静默降级，不卡状态机）
- **与任务计时双向打通**：任务卡上开始计时会自动绑定并启动番茄钟，反向亦然；任务时长与专注时长分别按真实秒数独立收账
- 专注历史统计面板：
  - 今日专注时长
  - 本月累计专注
  - 年度专注统计
  - 总体专注时间
- 专注完成后自动统计数据，并伴有视觉反馈
- 可自定义显示哪些统计数据
- 可手动修改今日专注时长

### 🔥 实时热榜
- 多源热榜聚合（UAPI 主源 + NewsNow 备用源，数十种榜单可选）
- 缓存优先渲染（stale-while-revalidate）：离线不再干等超时，先展示缓存再后台更新
- 数据源未变更时切换设置不发重复请求

### 💰 记账与番茄币（学生向，原位替换了音乐模块）
- **首页账本卡片**：只放最重要的三个数 —— 本月预算剩余、今日建议可花、超支分类，
  外加番茄币账户与攒钱计划进度
- **轻量记账入口**：一句话记账（如「午饭 25 微信」，自动识别金额/分类/账户/收支方向）
  + 模板记账（早餐/午饭/奶茶/地铁等，点一下只补金额）
- **收支流水**：固定学生分类（餐饮/交通/学习/社交/娱乐/订阅/购物/医疗/应急/储蓄）
  与账户（微信/支付宝/银行卡/现金/校园卡），按日分组、可筛选可删除
- **月度预算两层**：总预算（本月生活费）+ 分类预算；
  「今日建议可花」会先预留还没存完的储蓄额度再按剩余天数均摊
- **番茄币 = 注意力货币**：1 个自然完成的番茄 = 1 币，暂停/中断不计，每日上限 20 币；
  独立币流水（获得/消耗/余额）；**币不是钱**，只能兑特权（默认：
  30 币=1 小时娱乐、50 币=一杯奶茶、80 币=周末睡懒觉、100 币=愿望清单购买资格）；
  兑换真实消费（奶茶）时会同时记一笔支出，避免账实不符
- **自定义兑换项**：兑换商店支持增删改（名称/图标/价格），可设为「特权」或
  「真实消费」（指定默认金额与支付账户）；校验规则在 core.js，坏数据自动丢弃，
  历史兑换次数在删除后保留
- **攒钱计划**：目标名称/金额/截止日/进度/每周建议存额；存钱记「储蓄」流水并推进目标；
  本周每存 50 元奖励 5 币（只做「存钱奖励币」和「币换特权」，不做「币换钱」）
- **周报复盘**：自动生成钱账/时间账/币账/计划账/攒钱账五张卡 + 一句话总结 + 下周建议

### 🎧 其他实用模块
- **每日灵感/答案之书**: 随机名言警句或答案之书功能，提供每日灵感
- **每日新闻简报**: 一键查看今日新闻摘要图片

### ⚙️ 个性化设置
-   **全局配置面板**: 点击右下角悬浮按钮打开。
-   **模块开关**: 可自由开启或隐藏任意模块，布局自动重排不留空位。
-   **背景设置**: 支持默认动态渐变、自定义图片 URL 或每日壁纸。
-   **数据持久化**: 所有配置、任务和统计数据均保存于浏览器本地（LocalStorage），刷新不丢失。
-   **数据容错**: 本地数据损坏时自动备份坏值并正常启动，配额超限有告警提示。
-   **番茄钟统计显示开关**: 可自定义显示哪些统计数据
-   **任务功能开关**: 可开启/关闭任务编辑和计时功能
-   **热榜源自定义**: 可从数十种热榜源中选择最多 5 个显示在主页
-   **动效降级**: 尊重系统"减弱动态效果"设置；页面切到后台自动暂停背景动画，节能省电
-   **响应式布局**: 桌面三列 → 窄屏自适应，600px 以下移动端可用

## 🚀 快速开始

本项目为纯静态页面，无需安装 Node.js 环境或构建工具。

1.  **下载**: 下载**完整仓库目录**（必须包含 `index.html` 与 `js/core.js` 两个文件，缺一不可）。
2.  **运行**: 直接使用现代浏览器（Chrome, Edge, Firefox, Safari）打开 `index.html` 即可使用。若只保存了单个 `index.html`，页面会显示"缺少 js/core.js"提示——这是逻辑文件，请一并下载。
3.  **天气**: 项目不内置 API Key，首次打开时天气模块会提示"未配置 Key"，需先在右下角设置 → 天气模块填入自己的高德 Key（见下方配置说明）。默认城市为北京，可点击天气卡片搜索切换城市。

### 浏览器插件一键收藏（可选）

`extension/` 目录附带 MV3 插件，可将任意网页一键添加到导航页：

1.  打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」→「加载解压缩的扩展」，选择本仓库的 `extension/` 文件夹。
2.  点击插件图标，首次使用需填写导航页地址（如 `file:///D:/CyberFocus/index.html`），填一次即记住。
3.  点「添加到导航页」，导航页会弹出预填好的确认框：标题和网址已带入，可在此选择分组和内置图标（默认落在上次使用的分组，回车即保存）；若浏览器拦截本地页面（未开「允许访问文件网址」），插件会自动降级为复制数据，回导航页 → 管理面板 → 「从剪贴板导入」或手动粘贴即可。

> 隐私说明：新增链接默认通过 `favicon.im` 获取网站图标（仅发送公网域名，显示为网站原始图标）。内网地址、IP、`localhost` 与无 TLD 主机名不会外发；如需完全离线或统一视觉风格，在编辑链接时给该链接选择一个内置图标（选择图标 → 任意非「自动匹配」格），即不再发起任何远程请求。

## ⚙️ 配置说明

### 关于"天气模块"与"Failed to fetch"
天气模块依赖高德地图 Web 服务 API。
1.  **必须自备 Key**: 项目**不内置**任何 Key。天气模块依赖高德 Web 服务 API，需自行申请后填入设置面板，否则天气模块不可用（其余功能不受影响）。
2.  **申请 Key**: 
    *   前往 [高德开放平台](https://console.amap.com/dev/key/app)。
    *   注册账号并创建应用。
    *   申请 **"Web服务"** 类型的 Key。
3.  **替换 Key**:
    *   点击页面右下角的 **设置 (⚙️)** 按钮。
    *   切换到 **天气模块** 选项卡。
    *   在输入框中填入你申请的 API Key 即可（支持随时清空）。

### 常见问题排查
*   **Failed to fetch / 网络请求失败**: 
    *   通常是因为浏览器的 **CORS（跨域资源共享）** 策略限制。
    *   本项目内置了代理机制：首先尝试直连高德 API，如果失败，会自动通过 `api.allorigins.win` 代理转发。
    *   注意：高德 Web 服务接口不支持浏览器跨域，直连通常会失败，因此请求实际上大多走第三方代理，你的 API Key 与查询参数会经过该代理服务。
    *   如果仍然报错，请检查你的网络连接，或者检查 API Key 是否已过期/超限。

## 🧑‍💻 开发者说明

### 目录结构

```
├── index.html          # 页面结构 + 样式 + 应用主逻辑（单文件应用主体）
├── js/
│   └── core.js         # 纯逻辑层（UMD）：进度计算 / 热榜归一化 / 截止状态 / 记账与番茄币领域规则
├── tests/
│   └── core.test.js    # 单元测试（73 用例，零依赖）
└── extension/          # 可选的 MV3 浏览器插件（一键收藏到导航页）
    ├── manifest.json
    ├── popup.html
    ├── popup.js
    └── icons/
```

`js/core.js` 不引用 DOM、localStorage、fetch 与定时器，环境信息（页面地址、当前时间）一律由参数注入，因此可以在 Node 中直接测试。index.html 启动时会校验该文件存在且方法齐全，缺失或版本不匹配时给出可读错误页而非白屏。

### 运行测试

```bash
node tests/core.test.js
```

零依赖，无需 `npm install`。测试用例锁定了进度算法的权重均分、legacy 进度固化、100% 封顶等历史上最容易改错的逻辑。

### 架构约定

- **纯逻辑进 core.js**：新增与 UI 无关的领域算法时，优先放进 `js/core.js` 并补测试；index.html 只保留薄包装（负责注入 `location.href` 等环境参数）。
- **数据容错**：所有 localStorage 读写经 `safeParse`/`safeSet` 收口，损坏数据自动备份到 `${key}.corrupt`。
- 项目暂无构建步骤、无包管理器，请勿引入需要编译的依赖。

## 🛠️ 技术栈

*   **HTML5 / CSS3**: 原生开发，使用了 CSS Variables 实现主题管理，Flexbox/Grid 布局和玻璃拟态 (Glassmorphism) 设计风格。
*   **JavaScript (ES6+)**: 原生逻辑，无框架、无构建、无包管理器。
*   **Icons**: [Phosphor Icons](https://phosphoricons.com/)，**已内联为 SVG sprite**（62 个 symbol），不依赖任何 CDN，离线可用。
*   **Storage**: `window.localStorage`（全部经容错封装读写）。
*   **测试**: Node 内置 `assert`，零依赖自制 runner。

#### 核心特性
- 所有数据本地存储（localStorage）
- 双文件架构：页面主体 + 可单测的纯逻辑层（传统 `<script>` 引入，双击即用）
- 动态背景动画效果（支持系统级减弱动态效果降级）
- 丰富的交互反馈（悬停、点击、过渡动画）
- 模态对话框设计统一且美观
- 自适应不同屏幕尺寸（含 600px 以下移动端）
- 任务拖拽排序
- 任务层级管理和进度追踪
- 跨零点自动重置（页面挂夜不过期）

#### 第三方服务集成
- 高德地图 Web 服务 API（天气信息）
- UAPI / NewsNow（热榜聚合，多源备用）
- 名言和答案之书 API
- 每日新闻简报 API
- Bing 每日壁纸 API（经 UAPI）
- api.allorigins.win（CORS 代理回退，仅天气直连失败时使用）

## 注意事项

1. 本应用完全基于前端技术构建，无需后端服务器支持
2. 所有数据存储于浏览器本地，清除浏览器数据会导致信息丢失（数据导入/导出功能在开发计划中，目前请勿把本应用当作唯一存放处）
3. 热榜与天气模块采用第三方免费接口，可能存在不稳定情况（热榜有缓存兜底，离线时仍可查看最近一次数据）
4. **隐私说明**：本应用不采集、不上传任何数据；但天气与热榜功能会向上述第三方服务发起请求，你的高德 Key 与查询内容会经过所列第三方（含 CORS 代理）服务器
5. 只保存单个 `index.html`（不带 `js/core.js`）时应用无法启动，页面会明确提示缺失文件
